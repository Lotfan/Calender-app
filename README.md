🌸 Cutieee Calendar App 🌸

A simple and adorable desktop calendar app built with Electron.


💖 About

Cute Calendar App is a lightweight desktop application that helps you:

📅 View dates in a clean, minimal layout

🌷 Stay organized in a calm, distraction-free space

🖥️ Run your calendar as a desktop app using Electron

Built with using:

⚡ JavaScript

🎨 HTML & CSS

🖥️ Electron
